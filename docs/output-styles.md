# Output Styles Reference

8 predefined output styles in `.claude/output-styles/` control how Claude formats responses.

## Available Styles

| Style | File | Best For |
|-------|------|----------|
| Table-based | `table-based.md` | Structured data, comparisons |
| YAML-structured | `yaml-structured.md` | Config-like output, nested data |
| Bullet points | `bullet-points.md` | Quick summaries, lists |
| Markdown-focused | `markdown-focused.md` | Documentation, formatted text |
| HTML-structured | `html-structured.md` | Web preview, rich formatting |
| TTS summary | `tts-summary.md` | Audio output via text-to-speech |
| Ultra-concise | `ultra-concise.md` | Minimal output, terse responses |
| GenUI | `genui.md` | Generative UI components |

## Usage

Output styles are referenced in agent configurations or skill definitions to control response formatting.
